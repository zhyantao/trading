本页用形式化记号描述本站「选基 → 选股 → 组合权重 → 调仓信号」的完整计算口径（含估算价格与估值因子）。所有公式与 src/selection_formula.py、src/price_estimate.py、src/factor_scoring.py 中的实现一一对应，参数表由代码直接生成；页面展示的「综合得分」为 100 · S（满分 100）。

2. 绩优经理集合

定义 1 · 候选经理（无历史负业绩）
M*={m∣rm≤20,∀f∈Fm:R1(f)≥0∧RΣ(f)≥0∧D(f)≥180}
M* = { m | r_m ≤ 20, ∀ f ∈ F_m : R_1(f) ≥ 0 ∧ R_Σ(f) ≥ 0 ∧ D(f) ≥ 180 }
按经理排名向下扫描补足 20 位；成立不足 180 天的新基金在关联表阶段已过滤。
定义 2 · 经理质量（排名越靠前贡献越大）
Qf=1Cf∑m:f∈Fm1rm,Qs=1Ms∑m:s∈Gm1rm
Q_f = (1/C_f) Σ_{m: f∈F_m} 1/r_m ; Q_s = (1/M_s) Σ_{m: s∈G_m} 1/r_m
后文的 Q̃ 表示对 Q 做式 (5) 的归一化。

3. 归一化算子

式 (5) · 缩尾、稳健标准化与 min-max
xi′=clip(xi,q0.01,q0.99),zi=clip(xi′−med(x′)IQR(x′),−3,3),x~i=xi−minjxjmaxjxj−minjxj
x' = clip(x, q0.01, q0.99); z = clip((x' − med)/IQR, −3, 3); x̃ = (x − min x)/(max x − min x)
缺失值按中性处理（z 记 0、x̃ 记中位数），常量序列 x̃ ≡ 0.5；这样接口偶发缺字段时不会把标的误判为低分。

4. 估算价格与估值因子

估算价格 P̂ 是「按公开历史价格序列外推的下一交易日参考价」，不是实时报价，也不是目标价。基金用日单位净值序列（无序列时用公开区间收益率折算），股票用前复权收盘价序列（无序列时用重仓它的基金净值漂移按季报权重代理，只给涨跌、不虚构绝对价格）。数据全部来自仓库内已有的缓存序列与全市场排行字段，不新增联网请求。

式 (9) · 对数收益与稳健缩尾
rt=clip(ln(PtPt−1),med(r)±c·1.4826·MAD(r))
r_t = clip(ln(P_t/P_{t−1}), med(r) ± c·1.4826·MAD(r)), c = 5，窗口 = 最近 120 日
分红、份额折算会造成单日 10%+ 的「假收益」；用中位数绝对偏差缩尾，避免污染 EWMA。
式 (10) · EWMA 漂移、波动与样本量收缩
μ^t=λμ^t−1+(1−λ)rt,σ^t=EWMA(r,λ),neff=1−λn1−λ,μ~=μ^n·neffneff+K
μ̂_t = λ·μ̂_{t−1} + (1−λ)·r_t ; σ̂_t = EWMA(r, λ) ; n_eff = (1−λⁿ)/(1−λ) ; μ̃ = μ̂_n · n_eff/(n_eff+K)
λ = 0.94（RiskMetrics），K = 20 为先验样本量；短的净值序列不参与序列口径，改走式 (12) 的区间收益率折算。
式 (11) · T+1 估算价、参考区间与估值信号
P^t+1=Pt·eμ~,I68=[Pteμ~−σ^,Pteμ~+σ^],Vraw=clip(μ~σ0,−3,3)
P̂_{t+1} = P_t·e^{μ̃} ; I_68% = [P_t·e^{μ̃−σ̂}, P_t·e^{μ̃+σ̂}] ; V_raw = clip(μ̃/σ₀, −3, 3)
μ̃ 先按 ±3σ₀ 截断；σ̂ 是标的自身 EWMA 日波动（用于 ±1σ 参考区间），σ₀ 是资产类别统一先验（基金 1.2%、股票 2.2%，用于把 V_raw 拉回同一风险尺度）。估算涨跌 = P̂/P_t − 1。
式 (12) · 降级口径与 Ṽ 的横截面归一化
μ~=∑jwj·ln(1+Rj)dj∑jwj·neffneff+K,V~=x~(Vraw),V~≡0.5 (missing)
μ̃ = (Σ_j w_j·ln(1+R_j)/d_j / Σ_j w_j)·n_eff/(n_eff+K) ; Ṽ = x̃(V_raw); 缺失 Ṽ ≡ 0.5
j ∈ {近1周, 近1月, 近3月}，d_j = 5/21/63 交易日，w = 0.5/0.3/0.2；无行情序列的股票按季报「汇总占净值比例」对重仓基金的 μ̃_f 加权代理。Ṽ 在候选池横截面上做式 (5) 的缩尾 + min-max；缺数据的标的取中性 0.5，既不奖励也不惩罚。

5. 选基公式

式 (1) · 基金多因子基准分（用于「基金排名」页与优化持仓 --composite）
Sfac(f)=1∑kwk∑k∈{ret,risk,stab,qual}wkφk(f)
S^fac(f) = (1/Σ_k w_k) · Σ_k w_k φ_k(f), k ∈ {ret, risk, stab, qual}
回报因子按 7 个周期收益的加权稳健 z-score 合成，并按每行「实际可用周期的权重和」归一；风险与稳定性先把各周期逐列标准化，消除近 1 月与成立来年化的量纲差异。
式 (2) · 全局基金综合得分
Sf=0.28z~(Ra)+0.12z~(R1)+0.22ln~(1+Cf)+0.18Q~f+0.08ln~(1+Df)+0.12V~f−0.15·1[R1<0∨RΣ<0]
S_f = 0.28·z̃(R_a) + 0.12·z̃(R_1) + 0.22·lñ(1+C_f) + 0.18·Q̃_f + 0.08·lñ(1+D_f) + 0.12·Ṽ_f − 0.15·1[R_1<0 ∨ R_Σ<0]
与「每位经理各取 3 只」不同，Cf 让被多位经理共同选中的基金获得共识加分；Ṽf 为式 (9)–(12) 的估算价格因子，同一基金的不同份额（A/B/C）按基础名称去重。
式 (3) · 全局选基（唯一榜单）
F*=Top3{Sf∣f∈F}
F* = Top_3 { S_f | f ∈ F } （同分依次比较 C_f、R_a、基金代码）
即「绩优标的」页的基金 Top3：综合所有经理只选 3 条，不是每位经理 3 条。

6. 选股公式

式 (4) · 股票共识综合得分
Ss=0.30ln~(1+Ms)+0.16ln~(1+Fs)+0.16ln~(1+Ps)+0.10(1−T~s)+0.16Q~s+0.12V~s
S_s = 0.30·lñ(1+M_s) + 0.16·lñ(1+F_s) + 0.16·lñ(1+P_s) + 0.10·(1−T̃_s) + 0.16·Q̃_s + 0.12·Ṽ_s
对数压缩防止单只基金的高仓位主导排名；Ms 与 Fs 分别按经理、按 Top3基金列表 去重计数；Ṽs 为估算价格因子，无行情序列时按重仓基金净值漂移代理。「股票排名」页与「优化持仓」的股票得分都使用 Ss。
式 (6) · 全局选股（唯一榜单）
G*=Top10{Ss∣s∈G}
G* = Top_10 { S_s | s ∈ G } （同分依次比较 M_s、F_s、P_s、T_s、代码）
即「绩优标的」页的股票 Top10：综合所有经理只选 10 条；完整的去重股票池（含综合得分）仍在「股票排名」页展示。

7. 组合权重与信号

式 (7) · 得分归一化的目标权重
wi=B·Si∑j∈PSj,wi≤wmax,wiRP=B·Si/σi∑jSj/σj
w_i = B · S_i / Σ_j S_j, w_i ≤ w_max ; w_i^RP = B · (S_i/σ_i) / Σ_j (S_j/σ_j)
B 为股票/基金大类权重桶（默认 30% / 70%），wmax 为单一持仓上限；启用风险平价时用覆盖经理数的倒数作为风险代理 σ。
式 (8) · 调仓信号净强度
Ns=∑m∈M*∑f∈Fm(Bf,s+−Bf,s−)
N_s = Σ_{m∈M*} Σ_{f∈F_m} ( B⁺_{f,s} − B⁻_{f,s} )
B+ / B− 为基金季度「重大变动」中累计买入 / 卖出占期初净值比例；按 |Ns| 与阈值 τ=1.0 比较，输出关注买入 / 关注卖出 / 继续关注。

口径边界：基金/股票候选来自公开披露的季报前十大重仓股与「重大变动」数据，属于季度滞后信息；净值与收益率来自第三方排行接口，可能存在披露延迟或口径差异。估算价格是「用历史价格序列外推的 T+1 参考价」，不含盘中实时行情、公告事件与分析师预期；没有行情序列的股票显示为「暂无」，其估值因子按重仓基金净值漂移代理或取中性 0.5，代理口径不代表个股真实涨跌。估算价格与估值因子仅用于数据研究，不构成投资建议。
